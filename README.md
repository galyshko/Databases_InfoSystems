Slice дозволяє вибирати частину даних за певним критерієм (наприклад, вибір конкретного місяця чи регіону).

Dice дає змогу вибирати дані за кількома критеріями одночасно (наприклад, продажі по певному продукту та регіону).

Drill-down допомагає деталізувати дані, переходячи від загальних показників до більш конкретних (наприклад, з продажів по країні до даних по містах).

Roll-up дозволяє узагальнювати або агрегувати дані, переходячи від деталей до більш високих рівнів (наприклад, з витрат по категоріях до загальних витрат).

Pivot змінює структуру даних, дозволяючи перегруповувати їх для більш зручного аналізу (наприклад, продажі по продуктам та регіонах).
